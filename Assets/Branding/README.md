# Taskglass mark

`taskglass-logo.png` is the selected raster logo generated with the built-in imagegen tool on 2026-10-29. Mode: generate, transparent background. Use case: logo-brand. No external generation client or package was installed.

The generation brief requested a clean, minimal Taskglass mark: an overlapping cyan and violet T, rounded geometry, solid fills, transparent background, no text, gradients, glow, noise or 3D treatment. The selected output retains slight tonal variation from generation. The original generated PNG is preserved here without pixel editing.

`scripts/Icon.swift` places the mark on a near-black rounded square and renders the native macOS icon sizes through AppKit. Generated iconsets and ICNS files stay in `.build` and the packaged app.

This project distributes the mark with its MIT license.

`app-icon.png` is the 256 px AppKit-rendered icon for the repository preview. The ICNS in each release contains all native icon sizes.
