# Taskglass 0.1.0

First open-source preview for Apple silicon Macs running macOS 14 Sonoma or newer.

- Native black interface with resource graphs, CPU core history and GPU engine activity.
- CPU, memory, GPU, storage, network, battery, temperatures and fans, wherever macOS exposes the counters.
- Experimental CPU/GPU/Neural Engine power on recognized M5 Pro/Max drivers with macOS 27. Neural Engine power is not utilization.
- Searchable process table and complete scrollable app/helper groups on resource pages, with CPU, memory and disk rankings.
- Process inspector with short CPU/memory trends, executable reveal and identity-checked quit actions.
- Bounded histories/caches, off-main sampling, deferred covered-window updates, pause/minimize/hide handling and remembered view settings.
- No monitoring packages, privileged helper, daemon, login item, telemetry or subscription.

## Install

Download the **arm64 unsigned DMG**, open it and drag Taskglass into Applications. The ZIP contains the same app for users who prefer it.

This preview is **not Developer ID signed or notarized**. If macOS blocks opening, use System Settings → Privacy & Security → Open Anyway after reviewing the source of the download. See [Apple's instructions](https://support.apple.com/en-us/102445). Do not disable Gatekeeper globally.

`SHA256SUMS.txt` verifies download integrity. GitHub artifact attestations identify the repository/workflow that built each file. Neither substitutes for Apple notarization.

```sh
shasum -a 256 -c SHA256SUMS.txt
# Optional, with GitHub CLI installed:
gh attestation verify Taskglass-0.1.0-arm64-unsigned.dmg --repo KushagraBharti/taskglass
```

## Validation and limits

[CI passed on macOS 15 and 26](https://github.com/KushagraBharti/taskglass/actions/runs/41000150630).

Physical hardware validation: M5 Pro, macOS 27.0.1, including a bounded GPU compute workload. CI builds for a macOS 14 deployment target and runs core tests on macOS 15 and 26 arm64 runners. This is not physical validation of every M-series configuration or of macOS 14 runtime behavior.

Hardware availability differs by model and macOS release. Unsupported values stay unavailable. Private power and sensor interfaces may change. Per-process GPU/ANE/network attribution and media-engine utilization are not available. Process memory can include shared allocations and should not be summed to estimate system memory.

Please include your chip, macOS version and app version in an issue when reporting a problem. Review screenshots/logs for private process names before sharing them.
