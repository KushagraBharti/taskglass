Taskglass v0.1.2 reduces repeated rendering, sorting and allocation work while preserving the resource views and accelerator accounting.

- More selective UI updates, shared process metadata, faster process ordering and reused native table cells.
- Native chart drawing with fewer graphics layers, bounded icon caches, and safe full link-time optimization.
- Cleaner source and documentation, with superseded experiments and reviews removed.
- In short local comparisons on the development M5 Pro, Overview used about 30% less CPU and 10% less physical memory. CPU details used about 46% less CPU, but its memory footprint did not improve. These are single local runs, not guarantees for every Mac or measurements of the CI-built download. See the repository's measurements document for methods and raw aggregates.

Local ABI, sampler, sorting and lifecycle checks passed. Real Metal and Core ML workloads verified GPU PID attribution and shared Neural Engine group accounting. The existing macOS 15/26 CI and release validation also run before publication. GPU counters remain driver-dependent, and ANE group time requires recognized macOS 27 layouts. No utilization percentages are invented.

This remains a free unsigned, unnotarized preview for Apple silicon on macOS 14+. Download the DMG and drag Taskglass to Applications. Follow the included instructions for normal Gatekeeper approval when required. Checksums and GitHub build-provenance attestations accompany the archives. No administrator helper, daemon or package dependency is installed.
