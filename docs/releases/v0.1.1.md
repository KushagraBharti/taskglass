Taskglass can now show which processes have observed GPU execution time, and which OS app groups have kernel-accounted Neural Engine activity.

- GPU process/app rankings, main-table column and inspector history, in milliseconds per second. Stable-client and PID-birth checks prevent counter resets from becoming spikes.
- Neural Engine resource-group time on recognized macOS 27 layouts, with expandable current members and shared work counted once. Per-process Neural Engine memory is a separate ranking and inspector history.
- Existing CPU, RAM, disk and system monitoring stays available on macOS 14 and later. Unsupported accelerator counters show a dash. No helper, root permission, new runtime or dependency is required.
- Real six-second Metal and Core ML workloads verified PID/group attribution on an M5 Pro running macOS 27.0.1. macOS 15 and 26 CI cover builds, sampler/lifecycle tests, rejected layouts and older-system fallback. Other physical M-series models have not all been tested.

ANE time is shared OS-group accounting, not individual-process utilization. GPU time is driver-observed execution duration, not a percentage of device capacity. Driver counters may miss short-lived clients. See the repository's accelerator-attribution document for details.

This remains a free unsigned, unnotarized preview for Apple silicon. Download the DMG, drag Taskglass to Applications, and follow INSTALL.md if macOS requests Open Anyway approval. SHA256SUMS.txt and GitHub build-provenance attestations accompany the archives. No Gatekeeper disabling is required.
